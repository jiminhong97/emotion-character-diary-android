# Design Resources

원본 Android Studio 프로젝트에는 감정 캐릭터, 배경, 버튼, Guide 화면 이미지와 커스텀 폰트 등 디자인 리소스가 포함되어 있습니다.

이 공개 포트폴리오 저장소는 Java/XML 구현 로직을 보여주는 목적이므로 바이너리 디자인 리소스는 포함하지 않았습니다.

소스코드에서 다음과 같은 리소스 이름을 참조합니다.

- `emotion_happy`, `emotion_sad`, `emotion_tired`, `emotion_angry`
- 각 감정의 `*_big` 성장 이미지
- `bg_default`, `bg_happy`, `bg_sad`, `bg_tired`, `bg_angry`
- Guide 및 버튼 이미지

프로젝트의 기능 설계와 UI 흐름은 루트 README에서 확인할 수 있습니다.
